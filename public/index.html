File links for coding agents

An agent uploads a screenshot, recording or build with one request and gets back a public link it can put in a pull request. Uploading here needs my token. The code is open, so run your own. 

$ curl -T login-flow.webm -H "X-Upload-Token: $FILE_HOST_TOKEN" \
    https://files.lbgos.dev/login-flow.webm

https://files.lbgos.dev/f/1e452850091a42cab2b47fe36691651b/login-flow-a1b2c3d4.webm

Run your own

One container, Node 24, no database. Put it behind a TLS proxy that forwards Host.

git clone https://github.com/lbgos/file-upload && cd file-upload
cp .env.example .env   # FILE_HOST_TOKEN=$(openssl rand -hex 32)
docker compose up -d --build

Install the agent skill

Works with Claude Code and Codex (~/.codex/skills). The skill uploads files, embeds images in PRs and refuses to upload secrets. 

mkdir -p ~/.claude/skills/file-upload
curl -fsSL https://raw.githubusercontent.com/lbgos/file-upload/main/skill/file-upload/SKILL.md \
  -o ~/.claude/skills/file-upload/SKILL.md

Then point it at your host:

cat > ~/.config/file-upload.env <<'EOF'
export FILE_HOST_URL='https://files.example.com'
export FILE_HOST_TOKEN='<your token>'
EOF
chmod 600 ~/.config/file-upload.env

Behavior

Links
Unlisted, with a 128-bit random id. Anyone holding the link can open it.
Limit
90 MiB per file by default, below the Cloudflare 100 MB body cap.
Video
Range requests, so players can seek.
Safety
Files are served with a sandbox CSP and nosniff, so an uploaded HTML or SVG file cannot run script.
Delete
DELETE /api/files/<id> with the token.
